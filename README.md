# 🚀 Smart Money Concept Trading Bot

Professional automated crypto trading bot for Delta Exchange using Smart Money Concepts (SMC).

---

# ⚡ Quick Setup (First Time Setup)

## 1️⃣ Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/trading_bot.git
```

---

## 2️⃣ Open Bot Folder 

```
cd trading_bot
```

---

# 🔐 Setup `.env`

## Create `.env` File

---

## Paste Your Secrets

```
API_KEY=YOUR_API_KEY

API_SECRET=YOUR_API_SECRET

TELEGRAM_BOT_TOKEN=YOUR_TELEGRAM_BOT_TOKEN

TELEGRAM_CHAT_ID=YOUR_CHAT_ID

NEWS_API_KEY=YOUR_NEWS_API_KEY
```

---

## Save `.env`

---

# ▶️ Start The Bot

## Give Permission

```
chmod +x start.sh
```

---

## Run Bot

```
./start.sh
```

---

# 🛑 Stop Bot

Press:

CTRL + C
```

---

# 🔄 Update Bot From GitHub

Whenever you update code on GitHub:

```
git pull
```
